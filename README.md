### 🔮 Bank Customer Churn Prediction
`Python` `scikit-learn` `XGBoost` `SHAP` `Pandas`

End-to-end ML classification pipeline predicting retail banking churn before it happens. Covers EDA, feature engineering, class imbalance handling, hyperparameter tuning via GridSearchCV, SHAP explainability, and probability-based risk segmentation.

| Metric | Result |
|--------|--------|
| Best Model AUC-ROC | **0.881** (XGBoost) |
| High-Risk Tier Actual Churn | **71.1%** (predicted prob >= 60%) |
| Dataset | 10,000 customers, 20.4% churn rate |
| Explainability | SHAP beeswarm, bar, and waterfall charts |

Top churn drivers: Age (SHAP 0.31), NumOfProducts (0.21), Balance (0.18). Three executive retention recommendations delivered directly from model output.
